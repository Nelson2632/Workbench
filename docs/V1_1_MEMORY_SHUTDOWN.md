# v1.1 Memory、收尾和可访问反馈

2026-10-29，基于 Recover PR #4。

- Night Shutdown 允许空反思；保存防连点，失败保留文字并可重试。移除成功提示中的强制复盘措辞。
- 新用户夜间提醒默认关闭，保留旧 localStorage 显式开关与时间。提醒检查 nightShutdown，文案“今天要收尾了吗？”，通知附带固定 Shutdown 路由，onAction 使用白名单路由。
- Timeline 按本地日期分组，实时订阅派生表。任务直接打开对应详情（含非今日任务）；其他来源进入只读原始记录页面，保留所属领域入口。已删除记录明确显示缺失；路由只允许业务事实表，不能通过 URL 读取安全表。
- Daily Memory 订阅实际事实变化；历史创建、改日期、删除会刷新对应日及已存在的历史聚合。刷新/写反思在写事务中读取最新另一半数据，避免覆盖并发写入。
- UI 刷新保留未保存反思；日期切换确认丢弃；保存期间禁止改写与切日。往年今天只显示已有真实记忆且有事实或文字的同日记录。
- Toast：info/success 使用 polite status，warning/error 使用 alert 且不自动消失，均可关闭；聚焦/悬停停止自动关闭；reduced-motion 取消出入动画。
- Today 待调整区改中性色，保持三主题变量和现有动效契约。

验证：317/317 单元、构建、contract 70/70、implementation 18/18 通过。新增浏览器空反思收尾、刷新保留草稿、源任务导航、持久 warning 与键盘关闭；远端 CI 后补结果。

无 schema/依赖变化。原生通知点击和 VoiceOver 需要真实系统验收；单元 mock 仅验证调度、默认偏好保留、路由参数，不冒充系统通知验证。旧记录变更会刷新已缓存历史日期，后续索引优化降低扫描成本。
