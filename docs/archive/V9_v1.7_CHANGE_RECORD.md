## 一、Part A · Clarification（描述修正，无回归）

1. SQLite → IndexedDB 术语替换（DP1.3 / DP1.7 / R1.4 / R1.7 描述性改写）
2. R1.3 transient 例子修正：`SQLite busy` → `IndexedDB 事务冲突 / 浏览器存储层 busy`
3. R6-13 语义修正：SQLite WAL 禁令 → IndexedDB 内部存储日志（WAL 等价物）禁令
4. DP1.3 整节替换为 IndexedDB Transaction Boundary

## 二、Part B · Implementation Change（新增实现要求，需完整回归，用户可观察行为不变）

1. **system_command_id 表规范**（DP1.5 CommandIdempotency 新增 `implementation` 块）
2. **Mutation Lane 串行队列实现要求**（R1.1：Promise-chain + 同 Dexie transaction + 入口 commandId 去重）
3. **备份落盘 Tauri 文件系统**（DP1.7 FileSystem 新增「备份快照落盘」；Q1.10 实现要求；Q1.6 Gate2 落盘验证 + 从文件系统恢复）
4. **Event Journal 无限保留**（DP1.1 新增 `retention: indefinite`，移除 30 天滚动裁剪）
