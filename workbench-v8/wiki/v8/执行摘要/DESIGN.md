## 2. 四套视觉体系总览

### D-01｜确定正式视觉体系

已经明确选择四套视觉体系，它们不是四个孤立皮肤，而是按场景分工：

| 场景 | 风格 | 定位 |
|------|------|------|
| 日常（白天默认） | ☀️ **A 晨雾书房** | 安静 / 温润 / 学习 / 长时间使用 |
| Windows 原生感 | 🪟 **C Windows Fluent** | 可手动切换，桌面模式原生感 |
| 夜间（晚上默认） | 🌙 **D 深色夜航** | 晚间学习 / 阅读 / 复盘 |
| 分析 | 📊 **F 数据驾驶舱** | 专用于复盘页（周/月/考试） |

#### 场景映射

```
日常
  ↓
晨雾书房

Windows 原生感
  ↓
Fluent

夜间
  ↓
深色夜航

分析
  ↓
数据驾驶舱
```

## 3. 视觉任务清单 D-01 ~ D-17

### 3.1 主题体系

#### D-03｜A：晨雾书房

**设计语言**：
- 暖白背景
- 淡蓝灰
- 低饱和强调色
- 大留白
- 轻阴影
- 柔和圆角
- 书房感

**核心关键词**：安静 / 温润 / 学习 / 长时间使用

---

#### D-04｜C：Windows Fluent

不是把布局改掉，只是视觉层替换。

**特点**：
- 半透明
- Fluent 卡片
- Mica 感
- Windows 字体
- 更紧凑的控件
- 更明确的窗口层次

尤其适合：桌面模式。

---

#### D-05｜D：深色夜航

不是纯黑，采用分层深色表面。

**色值规范**：

| 层级 | 色值 | 用途 |
|------|------|------|
| 背景 | `#0D1117` | 最底层 |
| 一级 surface | `#151B23` | 卡片 / 面板 |
| 二级 surface | `#1B2430` | 嵌套卡片 / 悬浮 |
| 主文字 | `#E8EDF4` | 标题 / 正文 |
| 次文字 | `#9AA6B2` | 辅助说明 |

**强调色**：低饱和蓝 / 青。

**目标**：晚间学习、阅读、复盘。

---

#### D-06｜F：数据驾驶舱

**只用于**：
- 周复盘
- 月复盘
- 考试复盘

**设计重点**：数字 + 图表 + 趋势 + 对比。

而不是：大卡片堆满屏。

---

### 3.2 设计系统基础

#### D-07｜统一 Design Tokens

必须建立统一的设计令牌体系，覆盖：
- 颜色
- 字号
- 圆角
- 阴影
- 间距
- 边框
- 动画

**间距示例**：
```
space-1   space-2   space-3   space-4   space-6   space-8
```

统一页面间距，避免每个页面各自为政。

---

#### D-08｜卡片系统统一

所有普通卡片统一以下属性：
- radius（圆角）
- padding（内边距）
- border（边框）
- shadow（阴影）

**避免**：
- 首页一个圆角
- 学习页一个圆角
- 复盘页又一个阴影

---

#### D-09｜减少卡片数量

当前设计容易走向"什么都是 Card"。V8 需要增加不同层级的容器：

| 容器类型 | 用途 |
|----------|------|
| **Section** | 页面分区，无背景或极淡背景 |
| **List** | 列表项，行式布局 |
| **Panel** | 功能面板，有边框但无重阴影 |
| **Card** | 重点内容卡片，有阴影和背景 |
| **Data Block** | 数据展示块，数字为主 |

不要把所有东西都装进白色盒子里。

### 3.4 动效与可访问性

#### D-14｜动效

**原则**：有意义才动。

**应该有动效的场景**：
- 页面进入
- 卡片翻转
- 任务完成
- 数据更新

**不应该**：所有东西都飞进去。

并支持 `prefers-reduced-motion`，符合无障碍实践。

---

#### D-15｜可访问性

至少保证：

| 标准 | 要求 |
|------|------|
| 普通文字对比度 | ≥ 4.5:1 |
| 大文字对比度 | ≥ 3:1 |
| 键盘操作 | 全功能可键盘操作 |
| Focus 状态 | 可见的 focus 指示器 |
| 语义标签 | 使用正确的 HTML 语义 |
| 缩放 | 200% 缩放不破坏核心功能 |

---

#### D-16｜响应式

虽然定位是 Windows 桌面，仍然保持三档体验：

| 设备 | 体验目标 |
|------|----------|
| **Desktop** | 主体验，完整功能 |
| **Tablet** | 可用，布局自适应 |
| **Mobile** | 查看 / 快速记录，不追求把桌面完全搬过去 |

移动端不追求"把桌面完全搬过去"。

---

#### D-17｜闪卡背景设计

**最终至少 5 种背景**：
- 晨雾
- 夜空
- 森林
- 琥珀纸页
- 极简

**背景采用**：Gradient + Blur + Noise + Pattern，而非高分辨率图片。

## 4. 主题详细规范

### 4.1 A 晨雾书房（白天默认）

**设计语言**：暖白背景、淡蓝灰、低饱和强调色、大留白、轻阴影、柔和圆角、书房感。

**核心关键词**：安静 / 温润 / 学习 / 长时间使用。

**适用场景**：日常工作、学习、白天默认主题。

### 4.2 C Windows Fluent（手动切换）

**设计语言**：半透明、Fluent 卡片、Mica 感、Windows 字体、更紧凑的控件、更明确的窗口层次。

**适用场景**：桌面模式，追求 Windows 原生应用观感。

**注意**：只替换视觉层，不改变布局结构。

### 4.3 D 深色夜航（夜间默认）

**色值**：

| Token | 色值 |
|-------|------|
| `--color-bg` | `#0D1117` |
| `--color-surface-1` | `#151B23` |
| `--color-surface-2` | `#1B2430` |
| `--color-text-primary` | `#E8EDF4` |
| `--color-text-secondary` | `#9AA6B2` |
| `--color-accent` | 低饱和蓝 / 青 |

**适用场景**：晚间学习、阅读、复盘。

### 4.4 F 数据驾驶舱（复盘专用）

**设计重点**：数字 + 图表 + 趋势 + 对比。

**适用页面**：周复盘、月复盘、考试复盘。

**禁忌**：不要用于普通页面，否则信息密度优势丧失。

## 5. Design Tokens 统一设计令牌

### 5.1 颜色令牌

```css
:root {
  /* 背景 */
  --color-bg:           /* 页面最底层 */
  --color-surface:      /* 卡片 / 面板 */
  --color-surface-2:    /* 嵌套 / 悬浮 */

  /* 文字 */
  --color-text-primary:   /* 标题 / 正文 */
  --color-text-secondary: /* 辅助说明 */
  --color-text-tertiary:  /* 占位 / 禁用 */

  /* 边框 */
  --color-border:        /* 默认边框 */
  --color-border-focus:  /* 聚焦边框 */

  /* 强调色 */
  --color-accent:        /* 主强调 */
  --color-accent-hover:  /* 悬停 */
}
```

### 5.2 主题类名

```
theme-mist     /* 晨雾书房 */
theme-fluent   /* Windows Fluent */
theme-night    /* 深色夜航 */
theme-data     /* 数据驾驶舱 */
```

### 5.3 间距令牌

```
space-1    /* 4px  */
space-2    /* 8px  */
space-3    /* 12px */
space-4    /* 16px */
space-6    /* 24px */
space-8    /* 32px */
```

### 5.4 圆角令牌

```
radius-sm    /* 6px  */
radius-md    /* 10px */
radius-lg    /* 16px */
radius-full  /* 9999px */
```

### 5.5 阴影令牌

```
shadow-sm    /* 轻阴影 */
shadow-md    /* 中等阴影 */
shadow-lg    /* 重阴影（悬浮） */
```

### 5.6 动画令牌

```
transition-fast    /* 0.15s ease */
transition-normal  /* 0.25s ease */
transition-slow    /* 0.4s ease */
```

## 6. 卡片与布局系统

### 6.1 容器层级

| 类型 | 视觉特征 | 适用场景 |
|------|----------|----------|
| **Section** | 无背景或极淡背景，仅间距分隔 | 页面大分区 |
| **List** | 行式布局，分隔线，无卡片背景 | 任务列表、备忘列表 |
| **Panel** | 有边框，无重阴影，浅背景 | 设置面板、筛选栏 |
| **Card** | 有背景 + 阴影 + 圆角 | 重点内容、数据卡 |
| **Data Block** | 大数字 + 小标签，极简 | 统计数据、指标展示 |

### 6.2 统一卡片规范

所有普通 Card 必须使用统一的：
- `radius: var(--radius-md)`
- `padding: var(--space-4)`
- `border: 1px solid var(--color-border)`
- `shadow: var(--shadow-sm)`

禁止在各页面自行定义卡片样式。

## 8. 动效与可访问性

### 8.1 动效原则

**有意义才动**：

| 场景 | 动效 |
|------|------|
| 页面进入 | 淡入 + 轻微上移 |
| 卡片翻转（闪卡） | 3D flip |
| 任务完成 | 勾选动画 + 轻微缩放 |
| 数据更新 | 数字滚动 / 渐入 |

**禁止**：所有元素同时飞入、无意义的弹跳动画。

### 8.2 减少动画偏好

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    transition-duration: 0.01ms !important;
  }
}
```

### 8.3 可访问性清单

- [ ] 普通文字对比度 ≥ 4.5:1
- [ ] 大文字对比度 ≥ 3:1
- [ ] 所有交互元素可通过 Tab 键聚焦
- [ ] Focus 状态有可见指示器（`outline: 2px solid var(--color-border-focus)`）
- [ ] 使用语义化 HTML（`<nav>` `<main>` `<section>` `<article>` `<button>`）
- [ ] 200% 缩放下核心功能不破坏
- [ ] 图片有 alt 文本
- [ ] 表单控件有关联 label

## 9. 响应式策略

### 9.1 三档体验

| 断点 | 设备 | 体验 |
|------|------|------|
| ≥ 1024px | Desktop | 完整功能，侧边栏常驻 |
| 768px ~ 1023px | Tablet | 侧边栏可折叠，布局自适应 |
| < 768px | Mobile | 侧边栏变抽屉，仅保留查看/快速记录核心功能 |

### 9.2 移动端原则

- 不追求把桌面完全搬过去
- 优先保证：查看今日、快速备忘、任务勾选
- 底部导航栏替代侧边栏
- 触控目标最小 44px
- 输入框字号 ≥ 16px（防止 iOS 聚焦缩放）
