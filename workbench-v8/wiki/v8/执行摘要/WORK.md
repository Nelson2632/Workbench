配套文档：

## 2. 当前基线

当前 V8 已经不是概念原型，而是明确的桌面应用架构，具备以下能力：

### 技术基线
- Tauri 2 桌面框架
- React 19 + TypeScript
- Vite 构建
- React Router 路由
- Zustand 状态管理
- Dexie / IndexedDB 本地数据库
- ECharts 数据可视化
- CSS Modules 样式隔离

### 桌面能力基线
- 全局快捷键
- 系统托盘
- 桌面通知
- 快捷备忘浮窗（主窗口 + 浮动窗口双窗口架构）
- V5 → V8 数据迁移
- 本地自动备份

### 导航结构基线
```
今日 → 计划 → 学习 → 记录 → 复盘 → 工具 → 设置 / 密码本
```

### 页面树基线
今日、计划、学习、记录、复盘、工具，以及快捷备忘、设置、密码本。

> **结论**：接下来的目标不是重新选型，而是在已有 V8 架构上，把"能运行的个人工作台"升级成"真正好用的 Personal OS"。

## 3. 核心产品理念：从工具集合到 Personal OS

### W-01｜重新定义 V8 的核心使用闭环

**优先级：P0**

把整个产品从"很多独立工具"变成"一个连续的信息循环"。

#### 最终闭环

```
计划
 ↓
执行
 ↓
记录
 ↓
统计
 ↓
复盘
 ↓
调整
 ↓
下一次计划
```

#### 核心数据链

```
Task
 ↓
Pomodoro
 ↓
Study
 ↓
Mistake / Knowledge
 ↓
Review
 ↓
Next Plan
```

这是 V8 最核心的产品逻辑。当前 V8 已经开始尝试把任务、番茄、学习、错题、阅读汇入复盘，但需要继续强化这条链。

## 4. 模块职责边界（冻结）

### W-02｜重新定义模块职责

**优先级：P0**

必须冻结以下边界，写进代码规范，否则未来一定重新出现功能重叠。

| 模块 | 定义 | 核心属性 | 支持能力 |
|------|------|----------|----------|
| **Memo 备忘录** | "现在想到的东西" | 临时、快速、不要求整理 | 转任务 / 转笔记 / 转错题 |
| **Note 笔记** | "以后还要回来看的东西" | 长期知识 | 标签、分类、知识点关联 |
| **Task 任务** | "我要做什么" | 必须具有行动属性 | 优先级、截止日、项目归属 |
| **Recurring Task 周期计划** | "它以后会反复出现" | 不是任务本身，而是任务生成规则 | 规则配置、自动生成 |
| **Knowledge 知识** | "我需要掌握什么" | 学科→章节→知识点三级树 | 掌握度、关联错题/闪卡 |
| **Mistake 错题** | "我曾经哪里做错了" | 错误记录与复盘 | 关联知识点、错误类型 |
| **Flashcard 闪卡** | "我要记住什么" | 间隔重复记忆 | 难度、掌握度、复习调度 |
| **Review 复盘** | "我过去表现如何，接下来怎么办" | 反思与反馈 | 自动数据填充 + 引导问答 |
| **Project 项目** | "一组有共同目标的任务" | 长期目标聚合 | 里程碑、进度、阶段 |

## 5. 功能任务清单 W-01 ~ W-29

### 5.1 首页与信息架构

#### W-03｜首页重构为「今日驾驶舱」

**优先级：P0**

当前 Today 页面已有：问候、日期、首页倒数日、今日三件重要的事、周期计划、今日专注、今日学习、今日复盘。方向正确，需要进一步压缩和优化。

#### 最终首页结构

| 层级 | 内容 | 说明 |
|------|------|------|
| **第一层：Today Hero** | 问候 + 日期 + 核心倒数日 | "晚上好，Marty / 2026年8月23日 · 星期日 / 距离高考 XXX 天" |
| **第二层：今日最重要的 3 件事** | 仅显示 3 个任务 | 不是所有任务 |
| **第三层：今日计划** | 周期任务 + 一般任务 | 显示已完成 / 总数 |
| **第四层：今日状态** | 小型数据带 | 学习 3h25 / 专注 6 / 任务 7/9 / 闪卡 26/32 |
| **第五层：今晚** | 今日复盘入口 | 不单独占巨大卡片 |

---

#### W-04｜首页必须降低信息密度

**优先级：P0**

Dashboard 首先应建立信息层级，而不是尽可能展示数据。

**首页只解决"今天"**，不应该在首页塞：
- 长期成绩
- 大量图表
- 全部项目
- 全部笔记
- 阅读库
- 热点
- 大量统计

否则首页又会退化成"控制面板"。

---

#### W-05｜重新设计侧边栏

当前结构本身可以保留，但需要减少视觉重量。

#### 推荐最终导航

```
  阅读

  备忘录
  笔记

🌙 复盘
  今日
  学科
  周

  番茄钟
  随机工具
  记账
```

设置和密码本保持底部。

---

#### W-06｜降低导航层级的心理成本

当前每个大模块都有 Layout + 子路由，代码上合理，但用户层面容易感觉"进入了一个软件里的另一个软件"。

**目标**：模块切换很明显，页面切换很轻。

每个模块都应该有：
- 模块标题
- 模块级快捷入口
- 内容页

而不是重复一套复杂导航。

### 5.2 任务系统

#### W-07｜任务系统重新划分

当前已有：Inbox / Today / Recurring / Projects。

#### 建议变为

| 分类 | 定义 |
|------|------|
| **收件箱 Inbox** | 尚未安排 |
| **今日 Today** | 今天必须处理 |
| **未来 Future** | 已安排但不是今天 |
| **周期 Recurring** | 规则管理 |
| **项目 Projects** | 长期目标 |

这样"任务"和"时间范围"非常清晰。

---

#### W-08｜周期计划必须只负责"规则"

**优先级：P0**

这是很重要的逻辑调整。周期计划"每天背单词"不是一条任务，它是一条规则：

```
每天
 → 生成任务
```

真实执行的数据进入 Task。

#### 数据流

```
RecurringTask
      ↓ generate
      Task
      ↓ completed
```

而不是修改周期计划本身。当前 V8 已经采用 `sourceRecurringId` 记录生成来源，这个方向是正确的。

---

#### W-09｜周期计划规则升级

支持的规则类型：

| 类型 | 示例 |
|------|------|
| 每天 | 每日背单词 |
| 每周 | 周一 / 周三 / 周五 |
| 每月 | 1 日 / 最后一天 |
| 每 N 天 | 每 3 天 |

需要解决的操作：
- 起始日期
- 终止日期
- 跳过一次
- 暂停
- 恢复
- 本次不执行

### 5.3 备忘录与输入

#### W-10｜备忘录变成 V8 的"输入接口"

**优先级：P1**

这是非常重要的。桌面端已经有快捷备忘窗口，因此它应该是整个系统最轻量的入口。

当前桌面架构已经有主窗口 + 快捷备忘窗口。

**快捷键**：`Ctrl + Shift + Space`

打开：
```
┌──────────────────────┐
│ 突然想到……            │
│                      │
│                      │
│                 Enter│
└──────────────────────┘
```

保存之后默认进入 Memo Inbox，之后可转任务 / 转笔记 / 转错题。

---

#### W-11｜增加 Memo 自动整理入口

**优先级：P1**

不要自动替用户分类。首页或备忘录页面显示：

> 3 条待整理备忘

点击后提供操作：
- `[转任务]`
- `[转笔记]`
- `[保留]`
- `[删除]`

这是很轻的整理机制。

### 5.4 学习系统

#### W-12｜学习系统重构为"知识闭环"

**优先级：P0**

#### 最终闭环

```
知识体系
   ↓
学习
   ↓
错题
   ↓
闪卡
   ↓
复习
   ↓
掌握度
   ↓
学科复盘
```

当前 V8 的知识树已经是：学科 → 章节 → 知识点，并且知识点可以存在掌握状态、错题等信息。下一步是把它真正变成核心索引。

---

#### W-13｜知识点成为学习系统的"中心节点"

一个知识点应该能直接看到：

```
知识点：导数单调性
掌握度：★★★☆☆

相关错题：12
相关闪卡：8
最近复习：2天前
学习次数：6
```

然后直接进入：学习 / 错题 / 闪卡 / 笔记。

这会让整个学习系统从"几个工具"变成"知识图谱"。

---

#### W-14｜闪卡系统

已经确定方向，闪卡包含以下字段：
- 问题
- 答案
- 学科
- 章节
- 知识点
- 难度
- 标签
- 复习记录
- 下次复习日期

---

#### W-15｜闪卡导入

**优先级：P1**

支持两种导入方式：

**CSV 导入**，字段：
```
学科, 章节, 知识点, 问题, 答案, 难度, 标签
```

**粘贴导入**：直接从 Excel / WPS 复制。

导入时自动：
- 匹配 / 创建学科
- 匹配 / 创建章节
- 匹配 / 创建知识点

---

#### W-16｜智能抽背

**优先级：P1**

**默认排序**：今天到期优先。

顺序：逾期 → 今日 → 即将到期 → 新卡

**评价等级**：

| 表情 | 等级 | 初始调度 |
|------|------|----------|
| 😣 | 不会 | 1 天 |
| 🤔 | 模糊 | 3 天 |
| 🙂 | 会了 | 7 天 |
| 😎 | 熟练 | 14 天 |

以后再考虑 FSRS，不要第一版就复杂化。

---

#### W-17｜闪卡视觉

核心原则：漂亮，但不能抢文字。

**主题**（至少 5 种）：
- 晨雾
- 夜空
- 森林
- 琥珀纸页
- 极简

**背景生成方式**：由 Gradient + Noise + Blur Blob + Texture 组合生成，不是一堆大图片。

### 5.5 复盘系统

#### W-18｜复盘系统重构

**优先级：P0**

最终复盘中心：
```
今日 / 学科 / 周 / 月 / 考试 / 模板
```

当前路由已经具备这一结构。下一步不是加页面，而是让每个复盘页面真正有独立目的。

---

#### W-19｜每日复盘

系统自动填充数据：
```
今日任务 7/9
学习 4h35
番茄 8
错题 5
闪卡 26/32
```

用户只回答引导式问题：
1. 今天最重要的事？
2. 今天最大的阻碍？
3. 哪件事估时错误？
4. 明天最重要的三件事？

---

#### W-20｜学科复盘

**优先级：P1**

例如：数学 · 本周

**自动显示**：
```
学习 9h25
任务完成率 82%
新增错题 17
闪卡复习 63
薄弱知识点 6
```

**用户回答**：
1. 本周最大漏洞？
2. 最大错误类型？
3. 下周准备怎么处理？

---

#### W-21｜周 / 月复盘使用数据驾驶舱风格

这是已经明确确认的视觉方向。也就是数据驾驶舱，但只用于：周 / 月 / 考试复盘。

普通页面不要全部做成数据驾驶舱，这样数据驾驶舱的信息密度才能发挥价值。

---

#### W-22｜复盘可视化

**优先级：P1**

| 图表类型 | 用途 |
|----------|------|
| 折线图 | 学习时长趋势 |
| 柱状图 | 各学科学习时间 |
| 环形 / 饼图 | 错题类型分布 |
| 趋势图 | 任务完成率 |
| 柱状图 | 闪卡复习量 |
| 热力图 | 月度学习热力图 |

---

#### W-23｜复盘不能成为"数据墓地"

每一份复盘最后必须出现"下一步"。

**示例**：
```
本周发现：
数学任务经常超时

下周调整：
① 每次任务预留 20% 缓冲
② 数学任务拆成两段
③ 周三安排一次数学复盘
```

也就是说：**Review → Plan** 必须形成反馈环。

#### W-29｜减少"打开页面"的需要

桌面端真正价值不是"网页变成 exe"，而是"系统级快速入口"。

比如：
- `Ctrl+Shift+Space` → Memo

而不是：打开工作台 → 记录 → 新建备忘。

## 8. 最终目标

这次优化不是"再加 20 个功能"，而是把现有 V8 变成真正的 **Personal OS**。

```
                今天
                 ↓
               计划
                 ↓
               执行
        ┌────────┼────────┐
        ↓        ↓        ↓
      学习      项目      生活
        ↓
      记录
        ↓
      数据
        ↓
      复盘
        ↓
      调整
```
